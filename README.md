# Plans and Goals — AI-Powered Personal Finance Telegram Bot

A Telegram bot for personal finance management, built with Python, aiogram, SQLAlchemy, and Google Gemini.

Plans and Goals helps users track income and expenses, manage budgets, set financial goals, and receive AI-powered insights through a conversational interface.

## Features

### Personal Finance Management
- Track income and expenses through Telegram messages.
- Organize transactions by categories.
- Support multiple currencies.
- Calculate balances and financial statistics.
- Store and retrieve transaction history.

### AI-Powered Financial Assistant
- Process natural-language financial messages using Google Gemini.
- Extract structured financial actions from user messages.
- Detect missing information and request clarification.
- Preview proposed operations before saving them.
- Require user confirmation before committing financial actions.

### Budgets and Notifications
- Create budgets for individual categories.
- Track spending against monthly limits.
- Monitor budget thresholds.
- Receive notifications when spending reaches configured limits.
- Detect accelerated spending patterns.
- Prevent duplicate notifications.

### Financial Goals
- Create savings goals with target amounts and deadlines.
- Track contributions to existing goals.
- Monitor goal progress.
- Support multiple financial actions in one request.

### Financial Insights
- Compare current and previous spending.
- Detect unusual expenses.
- Analyze spending patterns.
- Generate AI-powered financial recommendations based on available user data.

### Architecture Overview

- **Handlers:** process Telegram messages and callbacks.
- **AI module:** communicates with Gemini and validates structured responses.
- **Database layer:** manages users, transactions, categories, budgets, goals, and notifications.
- **Budget scheduler:** performs scheduled budget checks and sends notifications.
- **Keyboards:** provides Telegram inline keyboards.
- **Tests:** verify financial operations, AI handlers, budget logic, and notification behavior.

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/eduardtavalbi/tg-PAG.git
cd tg-PAG
```

### 2. Create a virtual environment

Windows:

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
```

Linux / macOS:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Configure environment variables

Create a `.env` file in the project root:

```env
BOT_TOKEN=your_telegram_bot_token
GEMINI_API_KEY=your_google_gemini_api_key
```

Obtain your Telegram bot token through [BotFather](https://t.me/BotFather) and your Gemini API key through [Google AI Studio](https://aistudio.google.com/).

**Never commit your `.env` file or expose API keys publicly.**

### 5. Run the bot

```bash
python main.py
```

The application initializes the database, starts Telegram polling, and launches the budget notification scheduler.

## Running Tests

Run the automated test suite:

```bash
python -m unittest test_financial_actions test_budget_scheduler test_budget_scheduler_full test_budget_month_reset test_budget_notifications test_budget_thresholds test_ai_handler -v
```

The tests cover financial operations, validation, AI interaction handlers, budget calculations, notification deduplication, and error handling.

## Security and Data Handling

- API credentials are loaded from environment variables.
- Database operations use asynchronous SQLAlchemy sessions.
- Financial actions generated by AI require user confirmation before being saved.
- Database constraints and ownership checks help protect user data.
- Tests use isolated databases where applicable.
